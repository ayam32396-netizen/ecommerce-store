# 🛍️ متجر إلكتروني Full Stack

تطبيق متجر إلكتروني كامل يشمل:
- 🏬 صفحة عملاء لعرض المنتجات والشراء (سلة مشتريات + إتمام الطلب)
- 🛠️ لوحة تحكم للأدمن لإدارة المنتجات والطلبات
- 🔐 تسجيل دخول للأدمن (JWT)
- ➕✏️🗑️ إضافة / تعديل / حذف المنتجات
- 📦 إدارة الطلبات وتحديث حالتها
- 🗄️ قاعدة بيانات SQLite (ملف واحد، بدون سيرفر خارجي)

## التقنيات المستخدمة
- **Backend**: Node.js + Express
- **Database**: SQLite (مدمجة داخل Node.js نفسه عبر `node:sqlite` - لا تحتاج أي تثبيت أو أدوات بناء إضافية)
- **Auth**: JWT + bcrypt لتشفير كلمات المرور
- **Frontend**: HTML + CSS + JavaScript عادي (بدون فريمورك)

> ⚠️ **متطلب مهم**: يحتاج المشروع Node.js إصدار **22.5 أو أحدث** (يفضل 22.13+ أو 24+) لأنه يعتمد على قاعدة بيانات SQLite المدمجة داخل Node.js. تأكد من تشغيل `node -v` والتأكد أن الرقم أكبر من 22.5.

## طريقة التشغيل

### 1. تثبيت المتطلبات
تأكد أن لديك Node.js مثبت (يفضل الإصدار 18 أو أحدث)، ثم نفذ:

```bash
cd ecommerce-store
npm install
```

### 2. إعداد ملف البيئة
انسخ ملف `.env.example` باسم `.env`:

```bash
cp .env.example .env
```

يمكنك تعديل القيم بداخله (البريد وكلمة مرور الأدمن الافتراضية، مفتاح JWT، رقم المنفذ).

### 3. تشغيل السيرفر

```bash
npm start
```

سيعمل السيرفر على: `http://localhost:3000`

- **صفحة المتجر (العملاء)**: `http://localhost:3000`
- **لوحة تحكم الأدمن**: `http://localhost:3000/admin`

### 4. بيانات الدخول الافتراضية للأدمن
- **البريد**: `admin@example.com`
- **كلمة المرور**: `Admin@123`

> عند أول تشغيل، سيتم إنشاء قاعدة البيانات تلقائياً في ملف `store.db`، مع زرع حساب أدمن ومنتجات تجريبية.

## هيكل المشروع

```
ecommerce-store/
├── server.js              # نقطة تشغيل السيرفر
├── config/db.js           # إعداد قاعدة البيانات وإنشاء الجداول
├── middleware/auth.js      # التحقق من صلاحية الأدمن (JWT)
├── routes/
│   ├── auth.js            # مسار تسجيل دخول الأدمن
│   ├── products.js        # مسارات المنتجات (عام + أدمن)

└── public/
    ├── index.html          # صفحة المتجر للعملاء
    ├── css/style.css
    ├── js/app.js
    └── admin/
        ├── login.html      # صفحة تسجيل دخول الأدمن
        ├── dashboard.html  # لوحة التحكم
        ├── css/admin.css
        └── js/admin.js
```

## مسارات الـ API

| Method | المسار | الوصف | محمي؟ |
|--------|--------|-------|--------|
| POST | /api/admin/login | تسجيل دخول الأدمن | لا |
| GET | /api/products | عرض كل المنتجات | لا |
| GET | /api/products/:id | عرض منتج واحد | لا |
| POST | /api/products | إضافة منتج | نعم |
| PUT | /api/products/:id | تعديل منتج | نعم |
| DELETE | /api/products/:id | حذف منتج | نعم |
| POST | /api/orders | إنشاء طلب جديد (العميل) | لا |
| GET | /api/orders | عرض كل الطلبات | نعم |
| GET | /api/orders/:id | عرض تفاصيل طلب | نعم |
| PUT | /api/orders/:id/status | تحديث حالة الطلب | نعم |
| DELETE | /api/orders/:id | حذف طلب | نعم |

## ملاحظات مهمة
- كلمات المرور مشفّرة باستخدام bcrypt، ولا يتم تخزينها كنص عادي.
- التوكن (JWT) صالح لمدة 8 ساعات فقط، بعدها يجب تسجيل الدخول مجدداً.
- عند إتمام طلب من العميل، يتم تلقائياً خصم الكمية من مخزون المنتج.
- يمكنك رفع صور المنتجات مباشرة من جهازك عبر لوحة التحكم (تُحفظ في `public/uploads/`).
- لأغراض الإنتاج الحقيقي، يُفضّل تغيير `JWT_SECRET` في ملف `.env` لقيمة قوية وسرية.
